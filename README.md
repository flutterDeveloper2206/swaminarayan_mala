# SwamiNaam

Jai Swaminarayan — Har Saans Mein Naam, Har Pal Mein Shanti.

Offline Flutter devotion app for daily Shri Swaminarayan Naam Jap, 108-bead mala, Sahajanand Namavali remembrance path, kids jap, stories, and sadhana tracking.

**Package:** `com.swaminaam.application`  
**Stack:** Flutter · Provider · Hive CE · EN/HI/GU

Independent devotion app inspired by publicly known Akshar-Purushottam tradition. Not an official BAPS product.

## Run

```bash
flutter pub get
flutter run
```
